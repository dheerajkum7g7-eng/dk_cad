What's new in 3.2

  • Pan and zoom no longer get stuck. A touch that Android took away mid-gesture used to leave the canvas half-frozen until the app was restarted. Fixed.
  • Offset tool. Tap a line, type a distance, tap the side — a parallel line, polyline, arc or circle is created.
  • Delete one measurement. Tap a single coordinate marker or distance to remove just that one, instead of clearing everything.
  • Cleans up after itself. The app now keeps its own storage inside a budget, so it stays healthy over months instead of slowly filling the phone.
  • Tells you about updates. A new version now announces itself inside the app.

Installing

  1. Tap Download for Android above.
  2. Chrome will warn that this file type can harm your device — that warning appears for every APK that did not come from the Play Store. Choose Download anyway.
  3. Open the downloaded file. Android will ask permission to install from this source — allow it once.
  4. Tap Install. Installing over an older DK CAD keeps your recent files.

Already have DK CAD installed? Just install this on top — nothing needs to be uninstalled first.
